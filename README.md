# 🎮 Jogo da Velha em Python

Um projeto simples de **Jogo da Velha (Tic Tac Toe)** desenvolvido em **Python**, onde o jogador enfrenta o computador diretamente pelo terminal.

## 📌 Sobre o projeto

Este projeto foi criado para praticar conceitos fundamentais de programação utilizando Python, incluindo:

* Variáveis
* Funções
* Listas
* Estruturas condicionais (`if`, `else`)
* Laços de repetição (`while`)
* Entrada e saída de dados
* Lógica de programação
* Biblioteca `random`

O jogo funciona em modo **Jogador vs Computador**, onde:

* O jogador utiliza **X**
* O computador utiliza **O**
* O computador escolhe posições aleatórias disponíveis no tabuleiro

---

## 🕹️ Como jogar

1. Execute o programa.
2. Você jogará com o símbolo **X**.
3. Escolha uma posição de **1 a 9**.
4. O computador fará sua jogada automaticamente.
5. O jogo termina quando:

   * um jogador vence; ou
   * ocorre empate.

---

## 🚀 Funcionalidades

✅ Exibição do tabuleiro no terminal
✅ Jogador contra computador
✅ Jogadas aleatórias do computador (`random`)
✅ Verificação automática de vitória
✅ Verificação de empate
✅ Validação de posições inválidas
✅ Impede jogar em espaços ocupados
